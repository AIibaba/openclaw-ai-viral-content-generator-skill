*AI-powered social media content engine for TikTok, YouTube, Twitter/X, and Instagram.*

A comprehensive viral content creation system that helps creators and marketers produce scroll-stopping content across all major social platforms. From trend analysis and hook writing to hashtag optimization and posting schedules, this skill maximizes your content's reach and engagement.

## Features

| Feature | Description |
|---------|-------------|
| Multi-Platform Content | Generates optimized content for TikTok, YouTube, Twitter/X, Instagram, and more |
| Trend Analysis | Identifies trending topics, sounds, and formats to ride the viral wave |
| Hook Generator | Creates attention-grabbing openings that stop the scroll and boost retention |
| Hashtag Strategy | Researches and recommends optimal hashtag combinations for maximum discoverability |
| Content Calendar | Plans and schedules content across platforms for consistent posting |
| Engagement Optimizer | Analyzes performance patterns and suggests improvements for higher reach |

## Getting Started

```bash
# Install via OpenClaw
openclaw install AIibaba/openclaw-ai-viral-content-generator-skill
```

## Usage

```
generate [platform] [topic]  # Create viral content for a specific platform
trending [platform]          # Discover current trends and viral formats
write hooks [topic]          # Generate scroll-stopping hooks
calendar [week/month]        # Plan your content schedule
analyze [post URL]           # Analyze a post's viral potential
```
